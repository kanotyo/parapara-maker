かんたんパラパラ

index.html をSafariまたはChromeで開くと使えます。
「歩く」「手を振る」「ジャンプ」を選ぶだけで、連続する8コマのパラパラマンガができます。
外部API・アカウント・サーバーは不要です。

追加機能
・コマを作った後、「このコマを保存」で表示中のコマをSVG画像として保存できます。
・ボタンや入力欄にフォーカスがないとき、左右矢印でコマ送り、スペースで再生・停止できます。
・配布するときはindex.html、export.js、keyboard.jsを同じフォルダーに置いてください。

開発時の動作検証（Python PlaywrightとChromiumが必要）
1. リポジトリ内で python3 -m http.server 18765 --bind 127.0.0.1 を起動
2. 別のターミナルで python3 tests/browser_smoke.py を実行
SVG保存内容、キーボード操作、既存の生成・再生、モバイル幅を確認します。
